# Публичное состояние

На 24.11.2026 README описывает IT.Control Community RC1, бесплатную локальную систему ручного учёта и инвентаризации. Это кандидат, не Stable. Публичный архив и контрольная сумма указаны в README и разделе Releases. Фактическую доступность и SHA-256 проверять перед сообщением о выпуске. В данной сессии добавляется только документация, архив не заменяется.
