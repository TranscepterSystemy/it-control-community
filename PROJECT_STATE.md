# Публичное состояние

На 24.11.2026 README описывает IT.Control Community RC1, бесплатную локальную систему ручного учёта и инвентаризации. Это кандидат, не Stable. Публичный архив и контрольная сумма указаны в README и разделе Releases. Фактическую доступность и SHA-256 проверять перед сообщением о выпуске. В данной сессии добавляется только документация, архив не заменяется.

## Оформление от 26.11.2026

README приведён к визуальному стилю сайта ИТ.Контроль: добавлены фирменная шапка, навигация и реальный пример интерфейса VPN с пометкой «вне Community». Инструкции, лимиты и условия использования сохранены. Проверены SHA-256 и целостность утверждённого RC1, версия внутри архива и действующие пути документации. Изменяются только публичная документация и иллюстрации; архив, контрольная сумма, тег RC1 и версия приложения не меняются.
